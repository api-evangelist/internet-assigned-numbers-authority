The signature file "root-anchors.p7s", a signature over the trust anchor file "root-anchors.xml", will be updated by the end of August 2021. The current signature file will expire in November 2021. We have taken this opportunity to generate the new "root-anchors.p7s" without intermediate certificates while the new “icannbundle.pem” file contains only the ICANN Root CA certificate in PEM format.

title: "Changes to HTTP service for example domains"
url: "https://www.iana.org/news/2024/example-domain-http-methods"
date: "2024-09-04"
feed_url: "https://www.iana.org/news.atom"
---
The websites served on the example domains (e.g. example.com, example.net, example.org, and example.edu) no longer support POST, PUT, DELETE, and PATCH requests. Attempts for those HTTP request methods now return a 405 (Method Not Allowed) status code.
